# Thư mục mẫu giọng GPT-SoVITS (Voice Clone)

Thả các file audio mẫu 5–10 giây vào thư mục này để tự động thêm giọng vào FlowStory Dashboard:

### Cách đặt tên:
Mỗi giọng gồm 1 file `.wav` (hoặc `.mp3`) và 1 file `.txt` tương ứng ghi đúng câu nói trong file mẫu:

- `thanh_tra_minh.wav` (File âm thanh mẫu 5-10s)
- `thanh_tra_minh.txt` (Ví dụ nội dung: "Màn đêm buông xuống, tôi linh cảm điều bất thường sắp xảy ra.")

- `sat_nhan_giau_mat.wav`
- `sat_nhan_giau_mat.txt` (Ví dụ nội dung: "Ngươi tưởng có thể thoát khỏi nơi này sao?")

- `nu_drama.wav`
- `nu_drama.txt` (Ví dụ nội dung: "Tại sao anh lại giấu em chuyện khủng khiếp đó?")

Dashboard sẽ tự động phát hiện các file này và hiển thị trong danh sách chọn giọng!
